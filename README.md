# AI Cinematic Studio

Desktop production workspace for planning, generating, and managing AI-powered films.

## Development

```powershell
npm install
npm run dev
```

Start PocketBase:

```powershell
npm run backend
```

Copy `.env.example` to `.env.local` and configure the local PocketBase URL and demo credentials.

PocketBase migrations are stored in `pocketbase/pb_migrations/`. Local database files and the PocketBase executable are excluded from Git.
